Task Dashboard

A modern responsive task management dashboard built using React, Vite, Tailwind CSS, and localStorage persistence.

#Features
- Create, edit, delete tasks
- Mark tasks complete/pending
- Search tasks
- Filter by status and priority
- Grid/List view
- Dark mode
- Responsive dashboard UI
- LocalStorage persistence

#Tech Stack
- React
- Vite
- Tailwind CSS
- React Icons
- UUID


#Installation
bash
npm install
npm run dev

#Design Decisions
- Glassmorphism inspired modern UI
- Responsive adaptive dashboard layout
- Dark/light mode support
- Persistent state using localStorage
